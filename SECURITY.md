# Security reports

This is experimental local developer tooling. Read [the security model](docs/security.md)
and [compatibility](docs/compatibility.md) before relying on a client boundary.

For a sensitive report, use GitHub's private vulnerability reporting interface
when enabled. Do not open a public issue containing transcripts, credentials,
customer data or a working exploit against somebody else's environment.

Supported release: the latest repository main. Host/client qualification remains
an operator responsibility; a template cannot validate every installed toolchain.
